# Portfolio listing

**Title:** Power BI Operations Dashboard | Python & SQL Data Cleanup

**Role:** Portfolio project: data preparation and dashboard development

**Description:**
Independent portfolio project using 99,441 real historical Olist orders from
Kaggle. A validated Python pipeline cleans six linked CSVs, preserves exceptions,
and produces reconciled SQLite and Power BI inputs. Four interactive report
pages explore delivery rates, late-order workload, merchandise categories and
data quality. Includes a native PBIX, editable report source, 15 tests, SQL
queries, refresh instructions and a practical user guide. Historical demo data;
not paid client work or a live production service.

**Skills:** Microsoft Power BI, Python, SQL, Data Cleaning, Data Visualization

**Repository:** https://github.com/ZakJRademacher/commerce-operations-powerbi

**Demonstration:** Use the actual Power BI page exports as previews. The PBIX
contains imported demo data; refresh reads validated local snapshots on demand.
